\# Lab 01 - Active Directory Installation



\## Objective



Install Active Directory Domain Services (AD DS) on Windows Server 2016 and create a new Active Directory domain.



\---



\## Environment



| Item | Value |

|------|-------|

| Virtual Machine | VirtualBox |

| Operating System | Windows Server 2016 Datacenter Evaluation |

| Computer Name | Server1 |

| Domain Name | aysegul.com |

| Server Role | Domain Controller |

| Static IP Address | 192.168.1.100 |

| Subnet Mask | 255.255.255.0 |

| Default Gateway | 192.168.1.1 |

| Preferred DNS | 127.0.0.1 |



\---



\## Installation Steps



1\. Installed Windows Server 2016 in VirtualBox.

2\. Configured a static IP address.

3\. Installed the Active Directory Domain Services role.

4\. Promoted the server to a Domain Controller.

5\. Created a new Active Directory forest named \*\*aysegul.com\*\*.

6\. Restarted the server.

7\. Verified the successful installation.



\---



\## Result



The Windows Server 2016 machine was successfully promoted to a Domain Controller.



The Active Directory forest \*\*aysegul.com\*\* was created successfully.
