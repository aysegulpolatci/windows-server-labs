\# Lab 02 - Organizational Unit (OU) Configuration



\## Objective



Learn how to create and manage Organizational Units (OU) in Active Directory.



\## Environment



\- Windows Server 2016

\- Computer Name: Server1

\- Domain: aysegul.com



\## Steps



1\. Open Server Manager.

2\. Open Active Directory Users and Computers.

3\. Right-click the domain.

4\. Create a new Organizational Unit.

5\. Create child OUs if necessary.

6\. Verify the OU structure.



\## Result



Successfully created Organizational Units for managing users and computers.
